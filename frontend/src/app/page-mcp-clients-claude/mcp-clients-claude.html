What you get

Quaks ships an agentic financial-analysis layer for Claude. The quaks-agents plugin bundles two skills that drive Claude through multi-step workflows on the Quaks MCP server, pulling market news, fundamentals, prices, and technical indicators from the live data feed.

Skill What it does
/quaks-agents:news-analyst Daily investor briefing or Q&A on market events, earnings, economic indicators, and stock-specific news.
/quaks-agents:financial-analyst-v1 Full fundamental + technical analysis (P/E, ROE, RSI, MACD, EMA, ADX) with BUY/HOLD/SELL signals and a USD 10,000 portfolio allocation.

Want a different tone or focus? Edit any agent's prompts at /insights/agents — changes sync straight to the Quaks MCP server, so the next time you run the skill in Claude the new prompts are already live. No plugin update, no redeploy.

Install in Claude Cowork

Cowork uses a GUI-driven install flow — plugins and connectors are added from Customize in the left sidebar, not via slash commands. Complete both steps below in order: install the Quaks plugin first, then add the MCP connector so its tools can reach the Quaks server.

1. Install the Quaks plugin

The plugin bundles the Quaks skills and agents. Because bsantanna/quaks is a GitHub-hosted marketplace, a Team or Enterprise admin registers it once for the organization; after that, every member can self-install from the Cowork plugin catalog.

Admin (one-time setup):

  1. Install the Claude GitHub App on the bsantanna/quaks repository (required for Cowork to sync the marketplace contents).
  2. Go to Organization settings → Plugins.
  3. Click Add plugin and choose GitHub as the source.
  4. Enter the repository in owner/repo format: 
    bsantanna/quaks
  5. Verify GitHub access when prompted, then set the distribution preference to Available for install (members opt in), Installed by default (members can uninstall), or Required (members cannot remove).

Members:

  1. Open the Cowork tab.
  2. Click Customize in the left sidebar.
  3. Click Browse plugins.
  4. Find quaks-agents and click Install.

2. Add the Quaks MCP connector

With the plugin installed, wire its tools to the Quaks MCP server by adding a custom connector. Available on Pro, Max, Team, and Enterprise plans (Free plans are limited to one custom connector).

  1. Still in the Cowork tab, click Customize → Connectors.
  2. Click +, then choose Add custom connector.
  3. Paste the Quaks MCP server URL: 
    https://quaks.ai/mcp/
  4. Click Add. Cowork prompts you to sign in on first use.
  5. Enable the connector in a Cowork chat with + → Connectors. The plugin's skills can now call into the Quaks tools.

Install in Claude Code

Claude Code registers a claude-cli:// deep-link handler with your operating system the first time you run claude. Clicking the button below opens a new Claude Code terminal session with the marketplace-add slash command pre-filled.

Open in Claude Code

Press Enter in the Claude Code window to add the marketplace, then run /plugin install quaks-agents@quaks to install the plugin (see Install manually below). Requires Claude Code v2.1.91 or later.

Install manually

Already in a Claude Code session? Run these two slash commands:

  1. Register the Quaks marketplace from its GitHub repository (owner/repo format). 
    /plugin marketplace add bsantanna/quaks
  2. Install the quaks-agents plugin to your user scope (the default). 
    /plugin install quaks-agents@quaks

Prefer a browser? Run /plugin to open the interactive plugin manager. The Discover tab lists installable plugins from every registered marketplace; press Enter on quaks-agents to pick an installation scope (user, project, or local).

References: Discover and install prebuilt plugins through marketplaces · Launch sessions from links · Customize Claude Code with plugins

From your terminal

Fire the deep link from your shell — the OS hands it to the claude-cli:// handler: 

# macOS
open "claude-cli://open?q=%2Fplugin%20marketplace%20add%20bsantanna%2Fquaks"

# Linux
xdg-open "claude-cli://open?q=%2Fplugin%20marketplace%20add%20bsantanna%2Fquaks"

# Windows (PowerShell)
Start-Process "claude-cli://open?q=%2Fplugin%20marketplace%20add%20bsantanna%2Fquaks"

Just want the MCP server, without the plugin and skills? This adds the Quaks endpoint directly to Claude Code's MCP config — no interactive session needed: 

claude mcp add-json quaks-ai '{"type":"http","url":"https://quaks.ai/mcp/"}'

Sign in on first use

The Quaks MCP server uses OAuth 2.1 with PKCE. The first time you invoke a Quaks tool, Claude opens your browser to the Quaks sign-in page.

  1. In Claude Code, run any Quaks command — for example /quaks-agents:news-analyst.
  2. Claude opens quaks.ai/mcp/authorize in your default browser.
  3. Sign in with the credentials emailed to you after joining the waiting list, then approve the requested scopes (openid, profile, email).
  4. Claude caches the access & refresh tokens locally — you won't be prompted again unless you revoke or uninstall the plugin.

Update, disable & uninstall

Refresh the Quaks marketplace listing so new plugin versions show up: 

/plugin marketplace update quaks

Temporarily disable the plugin without removing its config (re-enable with /plugin enable): 

/plugin disable quaks-agents@quaks

Remove the plugin entirely:

/plugin uninstall quaks-agents@quaks

Apply install, enable, or disable changes without restarting the Claude Code session: 

/reload-plugins
