What you get

Quaks ships an agentic financial-analysis layer for Hermes Agent. The bsantanna/quaks plugin bundles two skills that drive Hermes through multi-step workflows on the Quaks MCP server, pulling market news, fundamentals, prices, and technical indicators from the live data feed.

Skill What it does
quaks:news-analyst Daily investor briefing or Q&A on market events, earnings, economic indicators, and stock-specific news.
quaks:financial-analyst-v1 Full fundamental + technical analysis (P/E, ROE, RSI, MACD, EMA, ADX) with BUY/HOLD/SELL signals and a USD 10,000 portfolio allocation.

Plugin skills are opt-in — they don't appear in hermes skills list. Hermes loads one when its skill_view tool is called, or when your prompt clearly maps to it (e.g. “give me a quaks news briefing” or “analyze AAPL, MSFT, NVDA with quaks financial analyst”).

Want a different tone or focus? Edit any agent's prompts at /insights/agents — changes sync straight to the Quaks MCP server, so the next time you run the skill in Hermes the new prompts are already live. No plugin update, no redeploy.

Install in Hermes Agent

Requires Hermes Agent v0.10.0 or later, and an interactive session for the first MCP connection (browser-based OAuth). Run this from any hermes session: 

hermes plugins install bsantanna/quaks --enable

The install command clones the plugin into ~/.hermes/plugins/quaks/, registers the two skills with Hermes' plugin manager, and patches ~/.hermes/config.yaml with the Quaks MCP server entry: 

mcp_servers:
  quaks.ai:
    url: https://quaks.ai/mcp/
    auth: oauth

The patch is idempotent and non-destructive — it only adds the quaks.ai entry if absent, preserves the rest of your config, and writes atomically. If the existing YAML is malformed Hermes skips the patch with a warning rather than overwrite your file.

Sign in on first use

The auth: oauth entry triggers Hermes' built-in OAuth 2.1 + PKCE flow with dynamic client registration and on-disk token persistence.

  1. In a Hermes session, run any prompt that triggers a Quaks skill — for example “give me a quaks news briefing” — or call skill_view(name="quaks:news-analyst") directly.
  2. Hermes opens (or prints) the authorization URL at quaks.ai/mcp/authorize in your default browser.
  3. Sign in with the credentials emailed to you after signing up, then approve the requested scopes (openid, profile, email).
  4. Hermes caches the access & refresh tokens on disk — you won't be prompted again unless you remove the plugin or revoke access from the Quaks side.

Update & uninstall

Pull the latest plugin and skill revisions: 

hermes plugins update quaks

Remove the plugin entirely:

hermes plugins remove quaks

Removing the plugin does not strip the quaks.ai entry from ~/.hermes/config.yaml. To fully clean up, also delete the mcp_servers.quaks.ai block from your config and reload with /reload-mcp.
