
Is there a way to create a “open with Claude” button in html that installs a plugin in Claude desktop?!


Thought for 7s
Yes, there are practical ways to create an “Open with Claude” button in HTML that can help users install or interact with plugins/extensions in Claude Desktop, but it's not fully automatic like a one-click browser extension install.⁠Anthropic

Claude Desktop (the native macOS/Windows app) supports plugins/extensions primarily through MCP (Model Context Protocol) servers bundled as .mcpb files (previously .dxt). These enable one-click-ish installation. Claude also registers a custom URL protocol (claude://) for deep links that open the app directly.⁠Support.claude

How Plugin Installation Works in Claude Desktop

Developers package MCP servers into a .mcpb file (a ZIP archive with a manifest.json, server code, and bundled dependencies).
Users install by:
Downloading the .mcpb file.
Double-clicking it (or dragging into Claude’s Settings → Extensions window).
Clicking “Install” in the prompt (shows metadata, permissions, etc.).
This is designed for simplicity—no manual JSON edits or terminal commands needed.⁠Anthropic
Creating an “Open with Claude” / Install Button in HTML

You can make buttons that download the extension and/or open Claude Desktop. Here's an example:

<!-- Button to download the .mcpb extension file -->
<a href="https://example.com/my-extension.mcpb" 
   download="my-extension.mcpb"
   class="claude-button">
  Download & Install Plugin in Claude Desktop
</a>

<!-- Button to open Claude Desktop (e.g., start a new chat or Code session) -->
<a href="claude://claude.ai/new?q=Install%20or%20use%20my%20plugin" 
   class="claude-button">
  Open with Claude Desktop
</a>

<!-- Combined flow example -->
<button onclick="handleClaudeInstall()">Install My Plugin in Claude</button>

<script>
function handleClaudeInstall() {
  // Trigger download
  const downloadLink = document.createElement('a');
  downloadLink.href = 'https://example.com/my-extension.mcpb';
  downloadLink.download = 'my-extension.mcpb';
  downloadLink.click();
  
  // Optionally open Claude (may require user confirmation)
  window.location.href = 'claude://claude.ai/new?q=Open%20Settings%20to%20install%20the%20.mcpb%20file';
}
</script>
Styling tip: Use a nice button with Claude branding (e.g., their colors) and instructions like “Download .mcpb → Double-click to install”.

Deep Link Options (claude://)

These open the desktop app directly (launches it if closed):⁠Support.claude

claude://claude.ai/new — New chat (add ?q=Your%20prompt to prefill).
claude://code/new?folder=/path/to/repo — Start Claude Code session.
claude://cowork/new — Start Cowork session.
Other paths for existing chats/projects.
The OS handles the protocol (registered automatically by Claude Desktop). Test with open "claude://..." (macOS) or start "" "claude://..." (Windows).⁠Support.claude

Limitations

No fully automatic install from web: Browsers don't directly execute .mcpb files for security reasons. Users must download + double-click (or drag). This is similar to other desktop app installers.
User must have Claude Desktop installed — The button can prompt them to download it first (from claude.ai/download).
Permissions & security: Extensions show a review dialog with required permissions/config before install.
Best Practices for Your Button/Page

Provide clear instructions: “1. Download the .mcpb file. 2. Double-click it or drag into Claude Settings > Extensions. 3. Click Install.”
Host the .mcpb reliably and version it.
For developers: Use Anthropic’s tools (npx @anthropic-ai/mcpb init and pack) to build bundles. See the official guide for manifest details.⁠Anthropic
Test on macOS/Windows.
